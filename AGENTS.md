# Notes for AI agents

## Keep the README current

[README.md](README.md) is the repo's front page: what Battleplan is, what it does, the production and dev sites, what it's built with, and where the docs are. Update it in the same commit as the work that makes it out of date:

- **When something the README says changes:** a site address, what deploys where and when, the platforms or the stack, a feature it lists, or a doc it links to.
- **When a significant feature is added or removed:** add it to the feature list, or take it off. Significant means people using the app would notice: a new tab or screen, a new kind of content, a new way to sign in, a new app to import from. Fixes, polish, and changes inside an existing feature don't count.

Keep the README short. Details belong in [SPEC.md](docs/SPEC.md), [ARCHITECTURE.md](docs/ARCHITECTURE.md), and [ROADMAP.md](docs/ROADMAP.md).
